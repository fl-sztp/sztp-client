# Repository instructions

Follow [CONTRIBUTING.md](CONTRIBUTING.md), the canonical copyright and licensing
policy, when creating, copying, or modifying files.

- Preserve all existing copyright holders, years, license metadata, upstream
  attribution, and notices limiting ownership to modifications.
- Establish ownership before adding a claim. Do not infer ownership from Git
  authorship or AI tool use.
- Use appropriate SPDX headers or narrowly scoped external annotations. Do not
  modify generated files solely to add metadata or use placeholders to hide
  unresolved provenance.
- Run `reuse lint` and report its actual result and unresolved ownership questions.
  For licensing-only work, verify that other file content and behavior are unchanged.
